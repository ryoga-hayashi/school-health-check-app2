# 小学生向け学校健診事前学習アプリ

小学1年生が、側弯症検診の目的や流れを事前に学べるWebアプリです。

## 制作背景

学校の集中講義におけるグループワークで制作しました。班に元保健室教諭がおり、限られた健診時間の中では、児童一人ひとりに検査の目的や方法を十分に説明することが難しいという課題を伺ったことが、開発のきっかけです。

## 目的

児童が健診の内容を事前に理解することで、不安や羞恥心を軽減し、安心して検診を受けられるようにすることを目的としています。

## 主な機能

- 側弯症と検診の目的を、やさしい言葉とイラストで説明
- スライダー操作による前屈動作の疑似体験
- 検診で確認する身体の位置を視覚的に表示
- 安心して検診を受けるための説明
- 学習内容を確認する3問のクイズ

## 工夫した点

- 小学1年生でも読めるよう、漢字をできるだけ減らしました。
- 文章を短くし、文字やボタンを大きくしました。
- イラストと操作を組み合わせ、検診の流れを直感的に理解できるようにしました。
- 痛みや怖さを感じたときは、大人に伝えてよいことを明示しました。
- 医療上の診断を行うアプリではないことを画面上に示しました。

## 使用技術

- Python
- Streamlit
- HTML / CSS
- SVG

## 実行方法

### 1. 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

### 2. アプリを起動

```bash
streamlit run app.py
```

`app.py`をPythonで直接実行して起動することもできます。

```bash
python app.py
```

## 制作形態

学校の集中講義におけるグループ制作です。本リポジトリには、ポートフォリオ掲載用として側弯症検診の事前学習機能を収録しています。

## 注意事項

本アプリは検診前の学習を目的とした試作です。疾病の診断、検査結果の判定、医学的助言を行うものではありません。
